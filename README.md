# Folio

一个本地优先的轻量 AI 文游框架与客户端项目。初期重点服务女性向 AI 文游玩家，帮助玩家导入已有自然语言剧本与长对话存档，在设备本地持久保存并在可控上下文下继续演绎故事。

## 当前路线

- **自研轻量文游 Harness + 纯本地存储**：不采用 DSH（DeepSeek Harness）等重型通用桌面 Agent 底座，也不依赖自建业务服务器、模型中转或电脑端配套。
- **最小实现先行**：先在本地网页端跑通核心文游 Harness 源码与播放闭环；当需要打包给种子用户在手机端试用时，再制作最小化 Android 封包；不考虑微信小程序路线。

当前仓库处于方案与验证规划阶段，尚未开始应用代码编写。首批工作是跑通本地网页端最小文游 Harness 闭环，验证剧本导入、流式对话、上下文摘要记忆与本地持久化方案。
