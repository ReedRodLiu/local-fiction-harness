# 双视图剧情树（分支总览 + 当前脉络）与规模感知分支折叠

> 演进自 [ADR 0007](0007-focus-path-story-tree-and-lazy-branch-labels.md)：在保留「聚焦主干的竖向时间线」与零模型预请求原则的前提下，解决超长篇（百轮以上）与高频试错（多处嵌套分叉、同路口数十次重试）下的分支发现、缩放与防误触问题。

## Decision

- **双视图结构（默认「当前脉络」+ 按需「分支总览」）**：
  - **当前脉络（Spine）**：继续作为默认激活视图，展示从故事起点到当前激活终点的主干路径、历史分叉路口与线性连续轮次折叠区间，确保单线游玩时的轻量阅读与既有交互契约不受破坏。
  - **分支总览（Overview）**：扁平化列出全树所有独立终端分支（叶子节点与其最近分叉路口之间的有效支线段落），内置纯本地实时搜索（匹配短标题、自定义名称、摘要预览、本地线索、祖先路径关键词与分叉轮次）与双排序（「最近游玩」/「推进量级」），支持 3 步以内从任意深层分支快速定位并切换。
- **单轮重试自动折叠**：未激活、未手动命名且无下级子分支的单轮重试节点（单节点助手重试，或同路口 3 条以上兄弟分支中的 1 轮试错路径）在「当前脉络」分叉卡片与「分支总览」中自动收纳至独立折叠区，不挤占有效剧情分支的视野与计数。
- **线性长区间 50 轮分段**：当「当前脉络」中某段无分叉线性区间的轮次超过 `SPAN_STAGE_MAX_TURNS`（50 轮）时，展开时先呈现按 50 轮切分的阶段分段列表（附分段预览与诊断计数），再按需展开具体分段内的节点只读预览，避免数百轮长篇一次渲染上千节点造成移动端卡顿。
- **纯本地零成本元数据与一键撤销切换**：分支短标题（`customName` > 归一化 `turnSummary` > 12 字纯文本预览 > 默认标签）、创建时间格式化（`YYYY-MM-DD HH:mm`，历史早于 2000 年的兼容时间戳显示为 `时间未知`）与线索提取全部纯本地完成、零 LLM 调用；在剧情树内执行分支切换时在顶部展示非阻塞「撤销切换」横幅，误触后可一键退回原激活分支。

## Considered Options

- **仅在「当前脉络」中逐层展开所有历史路口**：当故事存在 3 层以上嵌套分叉或 100+ 节点分支时，玩家需要逐层回忆并展开父分叉才能找到某条支线，无法直接按时间或规模检索。
- **在「分支总览」中一次性渲染整棵嵌套树图或自动调用模型总结所有分支**：窄屏手机下深层树图横向挤压严重且触控命中困难，自动调用模型则会显著增加导入与推演时的额外费用与延迟。
- **单次点击展开超过 500 轮的全部线性节点**：低端移动设备 WebView 中一次性挂载上千个节点预览 DOM 会导致明显掉帧与滚动迷失。

## Consequences

- `src/harness/storyTree.ts` 新增 `SPAN_STAGE_MAX_TURNS`、`projectStoryTreeSpanSegments`、`formatBranchCreatedAt`、`deriveBranchShortTitle`、`projectStoryTreeOverview`、`queryStoryBranches` 等纯函数投影能力，并向 `ForkSiblingBranch` 补充规模、时间与重试判定元数据，同时保持 `projectStoryTreeSpine` 与既有 `StoryTree` 契约完全向后兼容。
- `src/ui/StoryTree.tsx` 在遵循 ADR-0010 原生 CSS Design Tokens 与 `44×44px` 触控规范的前提下提供双视图切换、实时本地检索、单轮重试折叠、50 轮分段展开与撤销切换横幅。
