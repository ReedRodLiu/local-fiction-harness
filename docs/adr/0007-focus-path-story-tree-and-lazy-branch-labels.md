# 聚焦主干的竖向剧情树替代扁平翻页与全量展开

## Decision

用聚焦当前激活路径的竖向轨道**剧情树（Story Tree）**重构分支选择与进展查看体验（统一用于日常游玩与 DeepSeek 导入预览）：主视图仅展示从起点到当前激活分支终点的路径，将中间无分叉的线性连续回合自动折叠为单行区间摘要，并在曾发生分叉的历史路口节点标注 `⑂ N` 分支数量徽标；未激活旁支默认保持折叠且不预先调用模型生成重标签，仅在玩家点开某路口后先展示纯本地规则提取的时间/地点/标题/状态线索，按需触发模型提炼梗概并支持手动命名分支。

## Considered Options

- **延续传统大模型网页端的节点级 `< 1 / N >` 翻页器**：玩家在分叉点外无法宏观感知整部故事的岔路口分布、时间线跨度与不同路线的剧情推进深度。
- **默认全量展开整棵树并为所有分支自动调模型写梗概**：在数十轮、多处试错分支的移动设备上会严重挤占视野并带来不必要的额外模型调用成本。

## Consequences

- 长篇故事在手机窄屏下仍能一屏定位所有历史岔路口并迅速切换分支，同时把分支视图改造收益通过单一共用 UI 代码同步带给 Web 与 Android APK。
- 分支进展标签优先依赖轻量本地规则抽取与玩家手动命名，避免在正常推演与导入路径中隐式增加模型费用。
