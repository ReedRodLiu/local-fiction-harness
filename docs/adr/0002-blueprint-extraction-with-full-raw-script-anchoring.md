# LLM 蓝图拆解与原始剧本全量锚定并存

## Decision

导入 `.docx`/`.md`/`.txt` 或粘贴的自由格式剧本时，调用模型拆解生成结构化的故事蓝图（Story Blueprint）供玩家查看、微调与确认，同时在每次对话请求的固定锚定区始终完整保留原始剧本（Raw Script）全文作为兜底约束。

## Considered Options

- **强制用户按固定模板重写剧本或仅依赖拆解后 JSON**：对真实多维 Word 表格、伪代码块状态栏和严苛禁忌长剧本极易丢信息，也违背零门槛导入初衷。
- **完全不做结构化拆解、直接裸传全文**：玩家导入后无法验证 AI 是否正确理解主角、NPC 与核心禁忌，体验不透明。

## Consequences

- 蓝图拆解允许在模型输出残缺或截断时降级为 `partial_fallback`，不会阻断玩家进入故事。
- 固定锚定区会按剧本长度占用稳定输入 Token（实测长剧本可达 10K+ 字符），换取了规则不漂移与面板格式的高保真遵循。
