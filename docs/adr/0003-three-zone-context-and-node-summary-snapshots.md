# 三区上下文组装与节点冻结剧情摘要快照

## Decision

多轮请求采用「固定锚定区 + 滚动剧情摘要区 + 近期对话窗口」三区上下文结构，并将剧情摘要（Plot Summary）以不可变快照形式绑定到每一个节点（Turn Node），同时剥离推理链（`reasoning_content`）使之既不进入后续对话窗口也不写入剧情摘要。

## Considered Options

- **全局单一可变摘要字段**：实现简单，但玩家撤回重写或切换平行分支时，旧分支剧情已写入全局摘要，导致严重时间线污染或需要昂贵的重算。
- **全量历史消息无裁剪直传**：在长篇互动叙事下会迅速突破上下文预算并劣化指令遵循度。

## Consequences

- 任意节点回溯或平行分支切换均能以 O(1) 同步回滚到父节点冻结的摘要快照，彻底隔离分支记忆。
- 每个节点额外存储一份文本摘要快照，但文本量可控；需严格遵守由当前激活路径生成新节点并继承其父节点摘要的不可变更新契约。
