# 三种模式的首版试用

从欢迎页或书架打开文游、写故事或角色互动。三种模式可通过聊天请求改资料，核对 Markdown 后确认保存。公共记忆的修改影响之后发出的各模式请求；重访旧节点可看到当时的局部资料。

## 文游转写故事和半稿续写

1. 创建「浮灯渡口」，剧本写入「收灯人用三声钟响通知船主。钟响第三次之前，赤灯不可离岸。」先走一轮，打开最新回复的「从这里开稿」。
2. 在正文框填入「第二声钟刚停。阿霁把赤灯按在窗沿，背后响起一串湿脚印。」将光标置于末尾，输入「接着写一小段。保持短句，延续钟声伏笔。」核对建议并采纳。
3. 选中「湿脚印」，请求换一种感官写法，核对替换位置。修改正文后再采纳旧建议，检查是否提示重新确认。
4. 重开作品，检查正文及建议仍在。导出正文，检查文件只包含已保存稿件。

## 自由讨论后开新书

1. 打开写故事，选择「开新书」，填「纸月车站」。发送「主角替一座废弃车站写失物招领。谈两个低奇幻开场，然后比较第一幕节奏。」
2. 继续发送「选第一个。把已确定的背景总结存入本作品资料」，核对确认。确认前再次检查作品资料，确认后在作品资料中看到整理结果。
3. 选择「开始写」，直接写第一句或请求建议。可从开书讨论记录选一段引用。重开检查讨论和正文，导出只含正文。

## 角色互动

1. 新建「岑灯」，粘贴「退役夜航员，寡言，听完别人的话才开口。本人聊天用第二人称，对戏以动作承接。」分别从本人聊天和扮演对戏开始，确认各自进入历史对话。
2. 从旧回复继续，例如告诉岑灯「我以一位从未见过你的邮差身份回到码头」。模型处理初见、身份和场景承接。
3. 在本人聊天发一条合成私密文本。选择空白开聊，在第一轮检查请求未携带旧文本。如需保留一条资料，选择「带资料开新对话」并确认具体 Markdown。
4. 预览并导出选定路径，再确认删除选中的对话树。检查另一种互动和其他对话还可重开。
