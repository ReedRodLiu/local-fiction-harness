# Folio V0.5.1

Folio V0.5.1 正式发布：在 V0.5.0 通用 OpenAI 兼容多服务商架构之上，扩展多协议 Provider Presets，正式支持 OpenAI Responses API、Anthropic Messages 与 Google Gemini native 三种协议，并补齐 13 个国内外服务商预设与分类可折叠预设选择器。

## 更新内容

- **多协议 Provider Presets（#177–#181 / ADR-0020）**：
  - 新增多协议 base、OpenAI Responses API、Anthropic Messages、Google Gemini native 三种协议支持，扩展 13 个国内外服务商预设；
  - 补充 thinking dialects 与诊断 host，并提供分类可折叠预设选择器与多协议 E2E 覆盖；
  - 保证现有档案与备份在协议扩展下的平滑迁移。
- **代码评审修复（#176）**：
  - 合入多协议预设代码评审修复，提升预设选择与协议处理的稳定性。
- **版本号更新**：
  - 应用版本号正式升级为 `0.5.1`（Android `versionCode 11` / `versionName "0.5.1"`）。
