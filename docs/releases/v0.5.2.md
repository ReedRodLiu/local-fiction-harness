# Folio V0.5.2

Folio V0.5.2 正式发布：区分国内主流服务商的「按量 API 通道」与「Token 订阅 / Coding Plan 通道」，严格收敛显式协议选择，并修复 Google Gemini 官方 API 模型列表拉取、分页、非对话模型过滤与错误提示问题。

## 更新内容

- **双计费通道预设拆分（ADR-0021）**：
  - 将 9 家国内厂商的「按量 API 通道」与「Token 订阅通道」（如 `Kimi Code`、`GLM Coding Plan`、`阿里云百炼 Coding Plan`、`火山方舟 Coding Plan`、`MiniMax Token Plan`、`百度千帆 Token Plan`、`腾讯云 Coding Plan`、`商汤日日新 Token Plan`、`阶跃星辰 Step Plan`）拆分为并排独立预设（预设目录扩充至 30 项），并补充密钥隔离与订阅工具范围提示；
  - 修正商汤日日新按量付费端点为 `https://api.sensenova.cn/v1`，并把新增官方域名纳入脱敏诊断白名单；
  - 更新 `GLOSSARY.md` 与 `ADR-0021`，消费级 OAuth 订阅维持不纳入 BYOK 预设。
- **Google Gemini 官方接口与协议边界修复**：
  - 移除隐式 URL 协议自动推断，严格遵循用户选定或手动切换的接口协议；
  - 修复 `gemini_native` 裸域名缺 `/v1beta`、`/v1beta/models` 默认 50 条分页截断、`nextPageToken` 翻页异常、无 Key 返回 `403` 的误导提示，过滤生图/音频/转录/机器人/深度研究等非对话模型，并兼容 `AIza...` 与新格式 `AQ....` 提示。
- **版本号更新**：
  - 应用版本号正式升级为 `0.5.2`（Android `versionCode 12` / `versionName "0.5.2"`）。
