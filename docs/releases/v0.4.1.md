# Folio V0.4.1

V0.4.1 为应用图标专项更新版本，基于 V0.4.0 仅更换应用图标与对应版本号，无其他功能改动。

## 更新内容

- **全新 Folio 应用图标**：
  - Android 端替换 `mipmap-mdpi` 至 `mipmap-xxxhdpi` 全部自适应前景图（`ic_launcher_foreground.png`）、传统圆角图标（`ic_launcher.png`）与圆形图标（`ic_launcher_round.png`），并将自适应背景色 `@color/ic_launcher_background` 统一为深墨炭色 `#16171A`，贴合折叠象牙白纸页“F”与钴蓝书签徽标。
  - Web / PWA 端补充 `public/favicon.png`、`public/icon-192.png` 与 `public/apple-touch-icon.png` 并在 `index.html` 中完成挂载。
- **版本号更新**：
  - 应用版本号同步更新为 `0.4.1`（Android `versionCode 5` / `versionName "0.4.1"`）。
