# Folio V0.5.0

Folio V0.5.0 正式发布：在 V0.5.0-beta.1 通用 OpenAI 兼容多服务商架构之上，补齐 Android 端零配置免密钥公开网页联网查证兜底，并完成发行构建安全边界加固，正式从 Beta 迈入 V0.5.0 稳定版本。

## 更新内容

- **通用 OpenAI 兼容多服务商架构与 DeepSeek 一等预设（#159–#166 / ADR-0018）**：
  - 统一「连接模型服务」向导与多档案管理覆盖 DeepSeek 官方、OpenAI、OpenRouter、硅基流动、本地服务与自定义端点，支持模型列表拉取/手填双轨、跳过校验兜底保存与 Android 原生 Keystore 多密钥加密存储；
  - 默认关闭链式思考并支持故事、写故事与角色互动的作品级独立服务商/模型/思考覆盖；支持缓存命中感知的纯 Token 省量与自定义单价花费估算，`.folio.json` 全量备份严格剔除所有 API Key。
- **Android 端免密钥公开网页联网检索兜底（#167–#169 / ADR-0019）**：
  - 新增严格受限的原生 HTTPS 文本抓取桥接（仅 `https://`、单次 512 KB 上限与 10s 超时保护、绝不附带模型或搜索密钥），使 Android 端第三方服务商在未配付费搜索源时也能自动完成公开资料检索与正文提取；
  - 区分「默认自动（`auto`）」与「显式关闭（`none`）」检索语义，向导与设置页清晰提示 Android 端免密钥兜底与 Web 端静态无代理边界。
- **Android 构建安全隔离与发布审计加固（#170–#174）**：
  - 实现正式包与测试构建变体的网络安全策略源集物理隔离与 WebView 调试双重锁，升级发布前构建产物静态审计校验；
  - 配套补充 Android 真机 ADB + WebView CDP 混合自动化回归与多源产物硬门禁框架（含 [Runbook](../specs/android-adb-e2e-runbook.md)）。
- **版本号更新**：
  - 应用版本号正式升级为 `0.5.0`（Android `versionCode 10` / `versionName "0.5.0"`）。
