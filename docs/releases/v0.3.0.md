# Folio V0.3.0

V0.3 开放 DeepSeek 官方双模型与四档思考强度控制，新增官方账户总余额查看，并全面打磨写故事提案确认、静默自动保存、紧凑剧情树与移动端交互体验。

## 新功能与改进

- **DeepSeek 模型选择与四档思考强度滑块**：支持在日常轻量（`deepseek-flash`）与旗舰深度（`deepseek-v4-pro`）以及 `关闭 / 低 / 高 / 极限` 四档思考强度之间切换；设置页维护全局默认，各对话与写作输入区底部工具行支持按故事、作品、角色独立覆盖，后台摘要与导入提取固定使用轻量无思考配置。
- **查看 DeepSeek 账户总余额**：在「设置 → 连接 DeepSeek」连接卡片内自动查询并展示官方账户总余额，支持手动刷新与直达 DeepSeek 开放平台官方充值页。
- **写故事正文提案确认与静默自动保存**：试写与改写统一通过 `target: manuscript` 提案确认卡片预览差异后写入正文并支持一键撤销；正文升级为 1.5s–2s 静默防抖保存，补齐所有视图切换、导出与 Android 物理返回退出前刷盘。
- **紧凑剧情树与场景化等待轮播**：新增单轮摘要与 Markdown 纯文本清洗预览；全场景等待与思考折叠头采用场景化轮播文案；补充去“DS味”默认提示词、`lfh-choices` 容错解析与移动端无蓝框圆角按压反馈。
