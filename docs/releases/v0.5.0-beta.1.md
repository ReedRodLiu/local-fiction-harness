# Folio V0.5.0-beta.1 (V0.5 Beta)

V0.5.0-beta.1 正式将通用 OpenAI 兼容多服务商档案设为默认架构，让所有服务商平等接入，同时保留 DeepSeek 官方作为拥有全套原生增强的一等内置预设。

## 更新内容

- **多服务商档案库与统一连接向导（#159–#166 / ADR-0018）**：
  - 全新「连接模型服务」向导内置 DeepSeek 官方（省心全套）、OpenAI、OpenRouter、硅基流动、本地服务与自定义端点卡片，支持模型列表拉取与手填双轨、Web 端跨域通俗指引与跳过校验兜底保存；
  - 实时呈现 3 行通俗能力状态，并将后台轻量模型、自定义计费单价与「增强续写」一键兼容探测收纳进默认折叠的「更多可选设置」（严守应用内绝不内置破甲提示词边界）；
  - 设置页支持多服务商档案切换、新增、编辑与删除，Android 原生 Keystore 同步扩展支持完整档案元数据与多密钥加密存储。
- **默认关闭思考与三模式作品级覆盖**：
  - 全局与各服务商默认关闭链式思考（DeepSeek 关闭态显式禁思，第三方省略防 `400`），开启后按能力映射对应档位；
  - 文游、写故事与角色互动输入区支持跨档案/模型快速切换与独立覆盖，保留第三方配置下导入 DeepSeek 导出包能力。
- **分层联网检索、纯 Token 省量与无密钥备份**：
  - 第三方服务商严格主机隔离，可选配置 Tavily / 博查免费额度搜索预设或借用已连接的 DeepSeek 账号；
  - 流式用量解析兼容标准缓存命中字段，未填单价时展示纯 Token 省量估算，选填人民币/美元单价后自动估算花费；`.folio.json` 完整备份导出无密钥档案骨架，严禁包含任何 API Key。
- **版本号更新**：
  - 应用版本号同步更新为 `0.5.0-beta.1`（Android `versionCode 9` / `versionName "0.5.0-beta.1"`）。
