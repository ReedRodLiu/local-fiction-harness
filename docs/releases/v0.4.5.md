# Folio V0.4.5

V0.4.5 重点强化创作模式锁定保护与全局自然语言切模式二次确认，并修复 Android 真机在流式生成期间切屏或锁屏触发 `CONNECTION_ABORTED` 网络中断的问题。

## 更新内容

- **新建创作强锁定所选模式 + 全局自然语言切模式弹窗确认（#147）**：
  - 书架当前选中的创作分类（`文游` / `写故事` / `角色互动`）与「+ 新建创作」及欢迎页保持强锁定同步；仅当用户自然语言显式要求切换时才触发跨模式路由，不再仅凭题材猜测漂移。
  - 全局统一接入 `ModalDialog` 模式切换二次确认，覆盖欢迎页入口模式不一致与已有会话中自然语言切模式/跨模式 `lfh-proposal` 派生，取消时完整保留当前输入与已有会话，不产生多余条目（同步更新 `ADR-0012`）。
- **Android 真机切屏/锁屏 SSE 后台保活与有序缓冲（#148）**：
  - 新增活跃流专用 `dataSync` 前台服务（`SseForegroundService`）与引用计数保活协调器（`SseKeepaliveCoordinator` + 超时保护 `PARTIAL_WAKE_LOCK`），仅在流式请求期间挂载，结束或取消后立即停止释放，并安全降级处理未授通知权限场景。
  - 在 `NativeSsePlugin` 中增加 `onPause` / `onResume` 原生有序事件缓冲队列（`SseEventBuffer`），防止切屏期间 WebView 挂起丢帧或乱序，并在真实断线场景保留已收字节零正文诊断线索（同步更新 `ADR-0005` 与产物审计白名单）。
- **版本号更新**：
  - 应用版本号同步更新为 `0.4.5`（Android `versionCode 8` / `versionName "0.4.5"`）。
