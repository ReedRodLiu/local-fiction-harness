# Folio V0.4.2

V0.4.2 聚焦移动端交互手感、全屏页面滚动与手势动效体验打磨，并重构叙事预设快捷入口与设置子页。

## 更新内容

- **输入区聚焦边距与软键盘换行修复（#137）**：
  - 优化输入区聚焦边框外扩间距，消除贴字现象；修复移动端软键盘点击换行直接触发发送的问题。
- **设置页与导入页滚动及安全区顶栏修复（#138）**：
  - 为 `OverlayPageShell` 覆盖页补齐视口高度约束与滚容器边界，恢复单指垂直滑动；固定粘性顶栏在 `--safe-area-top` 下方，避免与系统状态栏重叠，并使异步错误与状态横幅可在当前覆盖层内正常展示。
- **书架画布右滑呼出与统一转场/侧滑返回动效（#139）**：
  - 书架抽屉支持从主画布非边缘右滑实时跟手呼出并联动遮罩透明度；全屏覆盖页与嵌套子页补全推入/推出转场、非边缘右滑返回及 `inert`/焦点恢复处理。
- **「叙事预设」单图标快捷入口与设置独立子页（#140）**：
  - 将主输入区两个常驻下拉框精简为工具栏单个「叙事预设」图标入口与快捷 Sheet，完整预设、`head/mid/tail` 槽位与前缀续写配置移入设置独立子页并统一术语分级。
- **版本号更新**：
  - 应用版本号同步更新为 `0.4.2`（Android `versionCode 6` / `versionName "0.4.2"`）。
