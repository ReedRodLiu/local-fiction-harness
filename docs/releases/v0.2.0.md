# Folio V0.2.0

V0.2 将三种创作模式整合到统一工作区，升级本地数据与备份格式，并为写故事提供可核对、可撤销的正文建议流程。

## 新功能

- 统一文游、写故事、角色互动的入口和创作阶段，支持自然语言意图分流。
- 使用 `.folio.json` v3 备份故事、对话、角色资料、记忆和显示偏好；不导出 API Key。
- 启动时自动迁移 V0.1 本地资料；导入旧 `.lfh.json` 时以非破坏方式合并。
- 写故事建议以卡片呈现，可查看 Markdown 差异、确认写入当前正文，并撤销已保存改动。
- 正文自动保存；流式输出格式不完整时保留可人工核对的提案卡片。
- 三种模式共享分支树和滚动摘要策略。
- 改进 DeepSeek 导入向导、安全 Markdown 展示和隐私诊断导出。

## 升级建议

安装前先导出 `.folio.json` 备份。V0.2 会自动迁移 V0.1 数据；更换设备时可通过备份恢复。首次使用模型功能时，仍需配置自己的模型 API Key。
