# Folio V0.4.3

V0.4.3 新增设置页全局省 Token 总表与分阶段首次启动引导蒙版教程，彻底独立三模式会话并保留 Skill 提案互通，同时修复 Android 真机滑动手势与流式自动滚动问题。

## 更新内容

- **设置页全局省 Token 与实测用量总表（#141）**：
  - 在「设置」新增 `省 Token 与用量总览` 看板，统计全工作区所有历史生成轮次（含分支与重试），展示累计预计省费、实测费用与未压缩基线对比、缓存命中率，以及「文游 / 写故事 / 角色互动」分模式统计。
- **术语与文案优化（#142）**：
  - 剧情树「分支总览」排序文案由「推进量级」调整为「最多轮次」，书架分类标签由「角色」统一为「角色互动」（同步更新 `ADR-0015`）。
- **模式会话独立化（#143）**：
  - 移除顶栏模式切换下拉与整段克隆逻辑，三种模式会话列表完全独立；保留欢迎页自然语言单入口分流，跨模式新建统一通过对话内 `lfh-proposal` 提案卡片（支持 `character` / `draft` / `story`）按需派生（同步更新 `ADR-0012`）。
- **Android 滑动手势修复（#144）**：
  - 补全滚动舞台与覆盖页 `touch-action: pan-y` 声明、调整触控判定阈值（`6px`）与系统边缘避让区（`32px`）、在横向锁定时获取指针捕获并补充零正文手势诊断埋点，解决书架左滑关闭与画布/覆盖页手势在 Android WebView 失效的问题。
- **两阶段首次启动引导蒙版教程（#145）**：
  - 首次启动应用（配置 API Key 前）与首次进入设置页分阶段弹出聚光灯蒙版引导，支持「下一步 / 跳过」及设置页「重新查看引导教程」，统一使用「叙事预设」「叙事连贯保护」等规范术语。
- **对话自动滚动跟随修复（#146）**：
  - 修复「写故事」「角色互动」将滚动目标绑在非滚动节点上的问题，合并高频流式 `requestAnimationFrame`、适配软键盘 `visualViewport` 变化并在发送/半拒绝追要时自动恢复跟随，同时补充零正文自动滚动诊断埋点。
- **版本号更新**：
  - 应用版本号同步更新为 `0.4.3`（Android `versionCode 7` / `versionName "0.4.3"`）。
