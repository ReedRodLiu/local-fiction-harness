# Folio V0.4.0

V0.4 围绕长剧情上下文压缩与计费透明度、Android 应用内自动更新、移动端稳定性及多模式枝桠管理完成全面升级。

## 核心新功能与改进

- **可回取上下文压缩与会话级省费面板（#121）**：
  - 在文游与创作对话的三区上下文组装中启用按需历史回取，仅读取当前分支与共享祖先中已被摘要覆盖的正分相关节点，绝不读取兄弟或远端分支；自动排除近期窗口、已注入设定节点与拒答记录。
  - 在文游、写故事与角色互动中持久化模型返回的真实 `LlmUsage`（缓存命中/未命中输入、输出及思考 token）及未压缩前文字符基线至 `.folio.json` v3 备份（不进入脱敏诊断导出）。
  - 在伴生面板内提供「实测用量与预计省费」视图：按 DeepSeek 官方公开分时费率与未压缩前文基线估算，非官方接口、缺少完整用量或尚未触发折叠压缩时明确显示原因，绝不伪造零值或占位金额。
- **Gitee Release 应用内检查更新与 Android APK 自动更新（ADR-0017）**：
  - 支持在「设置 → 关于与更新」手动或自动检查 Gitee Release 最新版本，应用内下载 APK 并完成 `SHA-256` 校验后调用 `FileProvider` 拉起系统安装器。
- **断线保活、精细错误提示与错误横幅防遮挡（#101）**：
  - Android 原生 SSE 流期间按活动流引用计数启用 `FLAG_KEEP_SCREEN_ON`，精细化识别 `CONNECTION_ABORTED / SOCKET_RESET / TIMEOUT / TLS_ERROR` 等网络异常并给出中文提示；错误与状态横幅收敛至输入区文档流内，杜绝遮挡末条消息操作栏。
- **叙事提示词包与拒答治理（#113）**、**公开资料低优先级参考（#122）**、**剧情树搜索与支线总览（#125）**、**模式切换防误触与损坏备份自愈（#126–#127）**、**流式 Markdown 渲染增强**。
