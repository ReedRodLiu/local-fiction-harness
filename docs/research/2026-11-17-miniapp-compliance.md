# 微信小程序 AI 文游本地播放器：窄范围合规研究

核查日期：2026-11-17。仅依据官方法规、主管部门公告及微信官方文档；未登录微信后台，未核验具体 AppID 或 DeepSeek 账户。只研究用户自带 DeepSeek API Key、自行导入剧本、开发方不设模型代理和内容市场的情形，不调整项目方案。下文“确定规则”指原文明确规定，“解释判断”不代表主管部门对本产品的认定。

**关键结论：这些设计不能直接推出版权、生成式 AI 或微信合规义务全部免除。** 不提供剧本分发会减少相关行为，但客户端调用在线 API 仍涉及对外生成服务的认定；谁付模型费用、开发方是否中转，并非已查规则中的独立豁免条件。也不能仅凭“文游”名称断言必需游戏版号，或凭“播放器”名称断言豁免。

## 1. 《生成式人工智能服务管理暂行办法》第二条

- **确定规则：** 第二条适用于利用生成式 AI 技术向境内公众提供内容生成服务；未向境内公众提供此类服务的研发、应用活动不适用。新闻出版、文艺创作等另有规定的，从其规定。第二十二条的提供者包括通过 API 提供服务的组织、个人。第十七条对具有舆论属性或社会动员能力的服务要求安全评估和算法备案。
- **解释判断：** 剧本和存档在本地、用户自己付费，不等于小程序没有向公众提供生成能力。向公众发布、组织提示词并呈现生成剧情，存在被认定为服务提供者的可能；纯工具定位同样不能直接排除适用。
- **未确认／待咨询：** 无开发方中转的自带 Key 客户端是否构成提供者，是否具有上述属性，应将真实调用、提示词和控制关系交属地网信部门确认。未找到专门覆盖此结构的官方豁免解释。
- 官方来源：[《暂行办法》第二、十七、二十二条](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)。

## 2. 模型备案、应用登记与小程序备案须区分

- **确定规则：** 网信办 2026 年 9 月公告明确，通过 API 或其他方式直接调用已备案模型能力的生成式 AI 应用或功能，由地方网信办开展登记；上线应用或功能应公示所用服务情况、模型名称及备案号或上线编号。工信部通知要求境内从事互联网信息服务的 APP 主办者履行备案，通知包括小程序分发平台；微信另有小程序备案流程。
- **解释判断：** 上游模型完成备案，不能直接代替下游应用登记；小程序备案也不能代替 AI 相关手续。这些文件不支持“只有自己训练模型才有手续”的说法。
- **未确认／待咨询：** 本结构是否属于登记对象、所选 DeepSeek 具体服务及版本的备案对应关系、应由谁申报，尚未核实；不能概括为“每个 API 客户端必需同样备案”。收费与电信许可的关系不在本次结论范围。
- 官方来源：[网信办备案／登记公告](https://www.cac.gov.cn/2026-09/14/c_1791136833136332.htm)、[工信部信管〔2023〕105号](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)、[微信小程序备案操作指引](https://developers.weixin.qq.com/miniprogram/product/record/record_guidelines.html)。

## 3. 微信 AI 类目、主体及资质：文档已读，个案未确认

- **确定规则（公开文档）：** 官方类目页显示最后编辑于 2026-11-16，在非个人主体下列有“深度合成—AI问答／AI创作”等，并非统一名为“生成式人工智能”的类目。其自研路线要求小程序主体的生成合成类算法备案；第三方路线要求技术主体的深度合成算法备案及小程序主体与技术主体的合作协议，协议包含算法名称、应用场景或备案编号相关内容。该表还要求 AI 内容显著标注。页面明确以提交时要求为准。
- **解释判断：** 自带 Key 没有直接解决“小程序主体与技术主体合作协议”的材料问题；普通工具类目不能被当作已确认的绕开路径。
- **未确认／待咨询：** 未登录后台，**本产品应选 AI问答、AI创作、拟人化互动、工具或游戏中的何种类目，个人／其他主体能否准入、实际材料和自带 Key 是否获接受，均未确认**。用户个人 API 合同能否满足上述主体要求，不能推定。
- 官方来源：[开放服务类目，定位“深度合成”](https://developers.weixin.qq.com/miniprogram/product/material/#深度合成)、[运营规范，第2.5.7及3.1节](https://developers.weixin.qq.com/miniprogram/product/)。访问说明：web open 失败后，以直接 HTTPS 请求取得官方 HTML 并读取表格；没有采用社区转载或代办机构说法。

## 4. 版权：个人导入与平台分享分别判断

- **确定规则：** 著作权法第十条保护复制、改编及向公众提供作品的信息网络传播等权利；第二十四条允许为个人学习、研究、欣赏使用他人已发表作品，但须符合署名、不得影响正常使用及不得不合理损害权利人利益等条件。信息存储服务的免责有法定条件，并非只要声称“用户上传”即可免责。
- **解释判断：** 用户合法持有并在本地私人使用，与开发方上传、推荐、分发剧本是不同事实。不设市场减少开发方分发行为，不能替用户取得授权。发送剧本给在线模型、生成改编和再发布，需分别判断；“导入”不自动等于合理使用。若平台增加公开链接、共享库或分享完整剧本，即使免费，也可能涉及向公众提供作品。
- **未确认／待咨询：** 剧本权属与授权范围、发送模型的内容和用途、平台是否知道侵权，以及具体输出是否侵犯原作，均未做个案判断。分享小程序入口不等同分享剧本；须核对分享载荷。
- 官方来源：[全国人大常委会公报《著作权法》，第十、十三、二十四条](https://wb.flk.npc.gov.cn/flfg/PDF/3d00c03d87cf4863878081a3e1b54638.pdf)、[《信息网络传播权保护条例》，第二十二、二十三条（CNNIC官方站刊载）](https://www.cnnic.cn/n4/2022/0819/c94-357.html)。

## 5. 2025 年生成合成内容标识

- **确定规则：** 《标识办法》及强制性国标 GB 45438-2025 自 2025-09-01 实施。办法第二条先限定适用主体；第四、五条分别规定相关生成服务的显式标识、文件元数据隐式标识，并涉及下载、复制、导出；第六条规定传播服务的核验和提示；第七条要求分发平台核验标识材料。第十条要求用户发布时声明、标识，禁止恶意去除标识。
- **解释判断：** 没有市场、没有公开分享，不直接排除生成服务自身的标识义务。若落入适用范围，只在简介写一次“使用 AI”不能据此证明满足全部要求。
- **未确认／待咨询：** 本客户端的主体认定、流式文本及纯文本／JSON存档的具体标识方式、上下游分别承担什么义务尚未确认；没有进行国标技术验收。第九条的无显式标识输出有协议和至少六个月相关日志等条件，不是默认免标识。
- 官方来源：[《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)、[国家标准现行状态及实施日期](https://std.samr.gov.cn/gb/search/gbDetailed?id=301E0388CB75788DE06397BE0A0AE1B4)。

## 6. 补核：拟人化互动服务办法已施行

- **确定规则：** 正式《人工智能拟人化互动服务管理暂行办法》（第21号令）于 2026-04-10 公布、**2026-07-15 施行**。第二条针对向境内公众提供模拟自然人人格、思维和沟通风格的持续性情感互动，包括陪伴、情感支持等；不涉及持续性情感互动的知识问答等服务不适用。适用时还涉及未成年人保护、AI身份提示、上线安全评估及算法备案（第十四、十八、二十二、二十六条）。
- **解释判断：** 普通剧情推进不当然等于持续性情感互动；长期角色陪伴、虚拟伴侣等功能需要特别核对，不能靠“用户导入角色”排除。
- **未确认／待咨询：** 文游角色互动是否达到第二条程度、自带 Key 情形由谁承担提供者义务尚无本产品的官方认定。微信类目表也已列“拟人化互动”，但个案准入未知。
- 官方来源：[正式规章全文](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm)、[微信类目页](https://developers.weixin.qq.com/miniprogram/product/material/#深度合成)。
