# RESEARCH-01：普通文游玩家的 BYOK 接受度与公开发行合规边界是什么？

## Question

针对希望省事、开箱即用的普通女性 AI 文游玩家，纯本地网页/最小 Android 安装包 + BYOK 模式在真实使用中有多高的配置门槛？在从内测走向公开发行前，需要满足哪些必要的合规与版权风险边界？

## Work

- 通过玩家访谈或社区一线样本调研，核实目标群体的设备分布（Android / iOS 占比）、当前使用 DeepSeek 替代工具的现状、获取与配置 API Key 的实操阻力，以及对工具付费和单次对话成本的心理预期。
- 基于已有[微信小程序合规调研](../../docs/research/2026-11-17-miniapp-compliance.md)的法规梳理，进一步核对当交付载体改为“纯本地客户端形态的独立网页或 Android 安装包”（无开发方模型代理、无剧本市场）时，网信登记/算法备案、GB 45438-2025 生成内容标识及《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行）在产品交互层面需要落实的最低要求。
- 梳理“用户自行导入本地剧本”场景下的版权风险提醒与产品边界设计（如严禁内置或分发未授权商业/同人剧本、清晰的用户内容声明与导出备份提示）。

## Acceptance

- 形成基于真实玩家样本或一手官方资料的 BYOK 门槛评估表，回答“是否需要做极简 Key 引导、首批测试优先覆盖哪些用户”。
- 产出清晰的“内测试用阶段 vs 面向公众公开发行阶段”产品合规与版权检查清单，明确哪些需在产品 UI/协议中前置落实、哪些需在公开上线前向主管部门或法务确认。

## Risks

- 目标玩家若绝大多数使用 iOS 设备或完全无法接受自行注册充值 API Key，将直接影响 Android 试用包和纯 BYOK 商业模式的有效性。
- 即便采用纯客户端与 BYOK，面向境内公众发布带有持续角色互动能力的应用仍可能触发相关 AI 标识或登记义务，不能简单假设“本地运行即完全免责”。
